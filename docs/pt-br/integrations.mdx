O OpenSRE investiga incidentes consultando as ferramentas que sua equipe já utiliza. Você pode conectar ferramentas para buscar logs e métricas, verificar implantações recentes e compartilhar resultados.

O projeto documenta mais de **60 integrações**. A disponibilidade de cada recurso depende da versão, permissões e configuração.

## Duas formas de configurar

| Forma | Ideal para | Configuração |
| --- | --- | --- |
| CLI local | OpenSRE executado no seu computador ou servidor | `opensre integrations setup` e variáveis de ambiente |
| OpenSRE Cloud | Conectores compartilhados por uma organização | [app.opensre.com](https://app.opensre.com) → Integrations |

As duas formas podem ser usadas separadamente. Se um serviço estiver conectado no aplicativo web e localmente, a conexão do aplicativo tem prioridade para sessões autenticadas.

## Configuração pelo terminal

```bash
opensre integrations setup
```

Também é possível configurar variáveis de ambiente, que serão carregadas na próxima execução. Consulte os requisitos específicos na página de cada integração e em [Variáveis de ambiente](/install/environment-variables).

### Verifique suas conexões

```bash
opensre integrations verify
opensre integrations verify datadog
```

No shell interativo, utilize `/integrations list`, `/integrations verify <name>`, `/verify` ou `/health`.

Para registrar instâncias separadas do mesmo provedor, como Grafana de produção e homologação, consulte [múltiplas instâncias](/platform/multi-instance-integrations).

## OpenSRE Cloud

Conecte os serviços em [app.opensre.com](https://app.opensre.com), na seção **Integrations**. O gateway e as sessões autenticadas podem reutilizar as conexões compartilhadas, conforme a configuração de sua organização.

## Cuidados

- Crie credenciais com o menor nível de acesso necessário.
- Prefira permissões somente leitura ao aprender e investigar incidentes.
- Não coloque tokens ou senhas em arquivos versionados.
- Confirme as permissões antes de habilitar remediações automáticas.

## Lista de funcionalidades

**CI/CD**

- Relatórios de confiabilidade de 30 dias, incluindo o impacto das falhas no tempo de desenvolvimento — [demonstração](/cicd/cicd-analytics-demo).
- Investigação e reparo de verificações do GitHub Actions com falha em branches ou pull requests — [guia](/cicd/github-ci-fix).
- Agentes recorrentes para acompanhar o estado do CI e executar reparos delimitados — [guia](/cicd/ci-repair-agent).
- Varredura somente leitura de falhas em branches e pull requests — [guia](/cicd/github-ci-health-scan).

**Integrações**

- Mais de 60 ferramentas para observabilidade, incidentes, nuvem, código, mensagens, bancos de dados e automação — [catálogo](/integrations).
- Configuração e validação usando `opensre integrations setup` e `opensre integrations verify`.
- Várias instâncias do mesmo provedor, por exemplo produção e homologação — [guia](/platform/multi-instance-integrations).
- Modelos de IA de diversos provedores, incluindo Anthropic, OpenAI, Gemini, Ollama, Bedrock e OpenRouter — [provedores](/platform/llm-providers).
- Conexões MCP pelo terminal (`/mcp`).

**Terminal interativo**

- Perguntas em linguagem natural, comandos com barra e ferramentas integradas — [assistente](/getting-started/interactive-shell-assistant).
- Referência dos comandos disponíveis em `/help` — [comandos](/getting-started/interactive-shell-commands).
- Objetivos persistentes entre interações — [objetivos](/getting-started/goals).
- Sessões que podem ser listadas, retomadas, resumidas e ramificadas — [sessões](/platform/sessions).
- Memória de longo prazo entre conversas — [memória](/platform/memory).
- Ajuste do esforço de raciocínio usando `/effort` ou `OPENSRE_REASONING_EFFORT`.

**Privacidade e segurança**

- Mascaramento reversível de identificadores antes de chamadas a modelos externos — [guia](/platform/masking).
- Controles de privacidade para o histórico de comandos — [guia](/platform/interactive-shell-privacy).
- Restrições para bloquear determinados segredos e informações pessoais.

**Mensagens e automação**

- Envio e acionamento de tarefas via Slack, Discord, Telegram e outros serviços — [mensagens](/integrations/messaging).
- Resumos e processos agendados com cron — [agendamentos](/platform/cron).

**APIs e implantação**

- API HTTP para verificações de saúde e recebimento de alertas — [API HTTP](/guides/api).
- API Python para incorporar agentes a processos — [API Python](/guides/python-api).
- CLI local, gateway gerenciado ou execução em Railway, ECS e Vercel — [implantação](/guides/deployment).
- Formas de instalação local e empresarial — [instalação](/install).

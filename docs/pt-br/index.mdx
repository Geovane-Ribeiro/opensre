## Escolha como executar

<Tabs>
  <Tab title="Terminal interativo">
    Instale, faça login e envie solicitações:

    ```bash
    curl -fsSL https://install.opensre.com | bash -s -- -dc
    opensre
    ```

    Para Windows, consulte o [guia de instalação](/install/windows-local). Revise o script remoto antes de executá-lo.
  </Tab>
  <Tab title="CLI sem interação">
    Execute uma tarefa a partir de um script ou pipeline CI:

    ```bash
    opensre --json ask "how many PRs currently have failing CI in Tracer-Cloud?"
    ```

    Veja o [guia da CLI](/guides/headless-cli) para saída JSON, permissões e entrada padrão.
  </Tab>
  <Tab title="Slack">
    Converse com o agente usando canais e mensagens diretas após configurar a [integração Slack](/integrations/messaging/slack).
  </Tab>
  <Tab title="Gateway gerenciado">
    Um administrador pode configurar o gateway organizacional em [app.opensre.com](https://app.opensre.com). Veja [Implantação](/guides/deployment).
  </Tab>
</Tabs>

## Como acontece uma investigação

1. Você informa um alerta ou descreve um problema.
2. O agente identifica o contexto e as possíveis causas.
3. Ele consulta logs, métricas e traces nas integrações disponíveis.
4. Analisa evidências e testa hipóteses.
5. Entrega uma resposta no terminal ou em outro canal configurado.

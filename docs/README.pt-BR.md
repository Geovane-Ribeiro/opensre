# Documentação do OpenSRE

Este diretório contém o código-fonte da documentação do OpenSRE, gerada com [Mintlify](https://mintlify.com).

## Desenvolvimento local

Para visualizar a documentação localmente, instale a CLI do Mintlify.

### Pré-requisitos

- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- [npm](https://www.npmjs.com/)

### Configuração

1. Instale a CLI do Mintlify globalmente:

   ```bash
   npm i -g mint
   ```

2. Inicie o servidor de desenvolvimento a partir deste diretório:

   ```bash
   mint dev
   ```

> Consulte [docs/README.md](README.md) para a configuração original e as instruções atualizadas.

## Estrutura

Os arquivos deste diretório organizam as páginas, os recursos e a configuração da documentação. Não traduza caminhos, chaves de configuração, comandos ou identificadores técnicos sem conferir onde são utilizados.

## Contribuições

Faça as alterações em uma branch, revise os links e a formatação e valide a prévia da documentação antes de propor a integração.
